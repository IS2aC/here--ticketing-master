# Autre événement

## Illustration

Événement privé sans type précis : élégant, chaleureux et soigné. Suivre d'abord la demande, le thème et la description. Sans indication : motifs floraux ou géométriques discrets, papier de qualité, couleurs du code couleur. Pas de personnage inventé. À éviter : symboles d'un autre type d'événement (alliances, ballons, lys) si la demande n'en parle pas.

## Propositions

- Choisir la composition d'après le thème et la description. À défaut :
- Classique : `mariage-feuillage-dore`, titre en Playfair Display, texte en Poppins, ivoire et or (or en accent).
- Moderne : `seminaire-ondes` clair, titre en Montserrat, vert sauge et encre foncée.
- Audacieuse : `seminaire-ondes` sur fond bleu nuit, titre en Bebas Neue, texte clair ; varier l'échelle du titre et l'accent plutôt que d'ajouter un décor festif.
- Ton : courtois et chaleureux, neutre tant que la description ne dit pas plus.
- Surtitres : « Vous êtes invité » ; « Rejoignez-nous » ; « Invitation ».
- Fins : « Nous serions heureux de vous compter parmi nous » ; « Votre présence nous ferait plaisir ».
- Mentions avant le nom : « Invitation pour » ; « Invitation personnelle pour ».
- À éviter : supposer le type d'événement ; le déduire seulement de la description.
