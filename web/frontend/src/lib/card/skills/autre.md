# Autre événement

## Illustration

Événement privé sans type précis : élégant, chaleureux et soigné. Suivre d'abord la demande, le thème et la description de l'organisateur. Sans indication : motifs floraux ou géométriques discrets, papier de qualité, lumière douce, couleurs du code couleur. Décor sur les bords et en haut, centre dégagé. À éviter : personnages, symboles d'un autre type d'événement (alliances, ballons, lys) si la demande n'en parle pas.

## Propositions

- Compositions : choisir d'après le thème et la description ; à défaut, `mariage-feuillage-dore` (classique), `seminaire-ondes` (moderne), `anniversaire-confettis` ou `festival-nuit-couleurs` (audacieuse).
- Polices du titre : Playfair Display ou Cormorant Garamond ; Montserrat ou Josefin Sans pour la moderne. Texte en Poppins ou Raleway. Nom de l'invité : Playfair Display ou Poppins.
- Palettes : tirées du code couleur ; sinon ivoire et or, bleu nuit et blanc, vert sauge et crème.
- Ton : courtois et chaleureux, neutre tant que la description ne dit pas plus.
- Surtitres : « Vous êtes invité(e) », « Save the date », « Rejoignez-nous ». Fins : « Nous serions heureux de vous compter parmi nous », « Votre présence nous ferait plaisir ».
- À éviter : supposer le type d'événement ; le déduire seulement de la description.
