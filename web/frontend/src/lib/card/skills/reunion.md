# Réunion

## Illustration

Réunion professionnelle ou associative : sobre, clair et moderne. Formes géométriques discrètes, lignes fines, aplats de couleur, léger relief de papier. Couleurs institutionnelles (bleu marine, gris, blanc, une couleur d'accent), ou celles du code couleur. Beaucoup d'espace vide. Pas de personnage. À éviter : poignées de main, salles de réunion, graphiques, chiffres, logos inventés.

## Propositions

- Classique : `seminaire-ondes` en version claire, marine sur blanc, titre en Montserrat, texte en Poppins.
- Moderne : `seminaire-ondes`, titre en Raleway, code couleur de l'organisation, accent franc.
- Audacieuse : `seminaire-ondes` sur fond sombre, titre en Bebas Neue, texte clair.
- Pas de `bapteme-douceur` ni de calligraphie.
- Ton : clair, courtois, sans formule de fête.
- Surtitres : « Réunion » ; « Invitation à la réunion » ; « Vous êtes attendu ».
- Fins : « Votre présence est importante pour la suite » ; « Nous comptons sur votre présence ».
- Mentions avant le nom : « Invitation nominative » ; « À l'attention de ».
- À éviter : ton familier, ordre du jour inventé.
