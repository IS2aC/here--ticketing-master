# Réunion

## Illustration

Réunion professionnelle ou associative : sobre, clair et moderne. Formes géométriques discrètes, lignes fines, aplats de couleur, léger relief de papier. Couleurs institutionnelles (bleu marine, gris, blanc, une couleur d'accent). Beaucoup d'espace vide. À éviter : personnes en costume, poignées de main, salles de réunion photographiques, graphiques et chiffres, logos inventés.

## Propositions

- Compositions : `seminaire-ondes` en priorité ; `bapteme-douceur` avec des tons neutres pour une réunion associative.
- Polices du titre : Montserrat, Raleway ou Josefin Sans ; Playfair Display pour une réunion plus formelle. Texte en Poppins ou Montserrat. Nom de l'invité : Poppins.
- Palettes : bleu marine, blanc et une couleur d'accent ; gris anthracite et vert ; le code couleur de l'organisation s'il est donné.
- Ton : clair, courtois, sans formule de fête.
- Surtitres : « Vous êtes convié(e) », « Réunion », « Invitation à la réunion ». Fins : « Merci de confirmer votre participation », « Votre présence est importante pour la suite ».
- À éviter : calligraphies, confettis, ton familier.
