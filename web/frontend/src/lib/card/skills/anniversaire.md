# Anniversaire

## Illustration

Anniversaire festif : ballons, confettis, serpentins, guirlandes lumineuses, bougies. Couleurs vives et franches pour un enfant ; pour un adulte, une palette plus posée tirée du code couleur ou du thème. Pas de personnage inventé. À éviter : chiffres et lettres dessinés, gâteau géant, paillettes partout.

## Propositions

- Classique : `anniversaire-confettis`, titre en Dancing Script, texte en Poppins, fond clair, titre et nom de l'invité en encre sombre.
- Moderne : `anniversaire-confettis` ou `mariage-feuillage-dore` pour un adulte, titre en Josefin Sans ou Playfair Display, deux couleurs du code couleur.
- Audacieuse : `festival-nuit-couleurs` pour une soirée, titre en Abril Fatface ou Bebas Neue, fond sombre, texte clair.
- `anniversaire-confettis` n'affiche pas de phrase de fin : mettre l'énergie dans le surtitre.
- ornamentTint à null pour garder des confettis multicolores.
- Ton : chaleureux, enjoué, direct. Le titre reprend le prénom tel qu'écrit ; l'âge seulement s'il est dans le titre ou la description.
- Surtitres : « Venez fêter » ; « C'est la fête » ; « On fête son anniversaire ».
- Fins : « On compte sur vous pour faire la fête » ; « Votre présence sera le plus beau cadeau ».
- Mentions avant le nom : « Une invitation pour » ; « On t'attend, ».
- À éviter : ton solennel, âge inventé.
