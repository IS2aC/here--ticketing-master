# Audit antislop 001 (19/11/2026)

Périmètre : `web/frontend/src` (pages, composants, éditeur de cartes), textes WhatsApp (`web/api/app/whatsapp/texts.py`), agent support (`web/hermes`), documentation.
Méthode : lecture du code et recherches ciblées. L'application n'a pas été lancée pour cet audit : aucun constat ne vient d'un clic réel.

Lecture : application d'invitations pour organisateurs d'Afrique de l'Ouest, dans la charte Here! (`uiux/visual-identity/DESIGN.md` : blanc, noir graphite, rouge Here, Poppins). Réglages : ÉNERGIE 2, RYTHME 2, MOUVEMENT 1 (DESIGN.md : 150 à 400 ms, rien de décoratif).

Priorité : HAUTE = règle absolue (Hard Gate), MOYENNE = technique admise seulement avec une raison (Purpose-Gate), BASSE = cohérence (Quality Locks).

Déjà conformes, rien à faire : les messages WhatsApp (courts, sans formule creuse, ton hôte et ton hommage distincts), les états de chargement (23 `Suspense` avec squelettes), `lang="fr"` et `data-theme`, focus visible sur les boutons et les champs (`outline-none` toujours remplacé par un contour intérieur), le lien « Bientôt » du portail admin (pas de lien mort), les capitales espacées des surtitres (voulues par DESIGN.md, `.text-caption`).
